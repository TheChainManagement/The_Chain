# Phase 5G — Base components (evidence)

*2026-05-31. Foundation sub-phase 5G. Per PROCESS.md Hard Rule 8 (leave evidence).*

## What was built

Six base components, each `src/components/<Name>/<Name>.tsx` + co-located
`.module.css` (tokens only) + co-located `.test.tsx`:

| Component | Role | States |
| --- | --- | --- |
| `StatNumber` | Canonical statistical-number render path (Plex Mono, tabular, deep slate; semantic tones, never cobalt) | value / empty (em-dash) / loading (shimmer) / error |
| `ClaudeInsight` | Canonical AI-explanation render path (Plex Sans prose + Plex Mono `Claude · {topic}` prefix; confidence = hairline track + deep-slate tick, never cobalt) | prose / loading (skeleton) / error / empty / +confidence |
| `ActionButton` | Canonical user-action render path (cobalt CTA w/ `--shadow-cobalt-inner` + `--shadow-cobalt-diffusion`; deep-slate focus ring; secondary = underline-scale link) | primary / secondary / loading / disabled |
| `Panel` | Flat work surface replacing "cards" (hairline border, blueprint corner-cut, focused inner-shadow, dotted lattice empty zone) | body / header+actions / empty (lattice) / loading / error / focused |
| `ChainLink` | The signature object — one PO chain link | done (pewter + cobalt corner dot) / active (cobalt fill + **ignite**) / pending / connectors cobalt|pewter|none |
| `MetricCell` | Metric-strip cell (border-divides, NOT cards). Composes `StatNumber`. | value / +delta (semantic) / loading / error |

The three trust-hierarchy components (`StatNumber`, `ClaudeInsight`,
`ActionButton`) are the canonical render paths per MASTER_PROMPT.

## Token discipline

- Every color / font / shadow / motion value is a CSS variable from
  `src/styles/globals.css`. No hex literals, no font-family literals in any
  component CSS (mirrors `samples/hero.html`; literal px is only per-element font
  size, which is not tokenized in the design system).
- Added two tokens: `--color-on-signal` / `--color-on-signal-dim` (text/glyphs on
  a cobalt fill) so white-on-cobalt is not a hardcoded `#fff`.
- Cobalt hierarchy honored: cobalt appears ONLY on the primary CTA and the active
  chain link in the gallery (2 of the max-4 allotment). Status uses semantic
  flow/warn/stop; confidence + deltas never use cobalt.
