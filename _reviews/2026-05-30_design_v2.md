## What wasn't done

1. **Cobalt accent count remains ambiguous (Finding 1, partial).** The strict hierarchy is documented in `DESIGN_DIRECTION.md` and respected for the four named intent slots, but `samples/hero.html` keeps cobalt corner-dots on done chain links and cobalt-tinted hairline connectors between done links. If those are intent slots, the cap is exceeded. If they are brand-mark touches within the single Chain component, the cap is respected. The direction does not carve this out, so the audit cannot resolve cleanly.
2. **Bench-bottom throughput hairline lacks the "today" marker described in DESIGN.md.** The DESIGN.md text says "Today's position marked with a small deep-slate 'you are here' tick." The `.bench::after` element renders the day-tick hairline correctly but no deep-slate vertical "today" tick is present at the current position. Time-axis ruler beneath the chain DOES have a today marker; the bench-bottom one does not.

## What can be done better

1. **Resolve the cobalt count ambiguity in writing.** Two clean paths: (a) tighten `samples/hero.html` to remove the cobalt corner-dots and cobalt-tinted hairline connectors (replace with neutral); (b) carve out "Chain-component brand-mark touches (corner-dots, connector hairlines) count as part of the active-chain-link intent slot, not as separate intent slots" in the DESIGN_DIRECTION.md cobalt hierarchy. Either way is defensible, but the doc and implementation must agree.
2. **Add the deep-slate "today" tick to the bench-bottom throughput hairline.** Small visible touch; closes the only documented atmosphere claim that did not ship.

## What was missed

1. **Visible-delta calibration (MG's "looks the same" instinct).** Approximate count: 7 changes below the visible threshold (variable renames, comment additions, doc-only sections, evidence-file restructuring) versus 12 changes that genuinely shift the page's character (shimmer animation, dotted lattice, scaleX scroll progress, Mona Sans variable-width axis usage, panel rename, focus-visible rings, trust-hierarchy section, footer fix, single fade-up headline, chain ignite animation, chain notched connectors, time-axis ruler). MG's instinct is partially right — the headline animation change is the biggest single visible move; many other wins are micro-level. The fix list addressed compliance correctly but did not commit to one large headline visual move (a dramatic typographic moment, a hero-scale chain animation, an entirely new section) that would have read as a redesign rather than a polish pass.
2. **No anti-convergence regression detected.** The re-run preserved divergence cleanly.
3. **No accessibility regressions detected.** `--color-dim` fix actually improves overall WCAG AA compliance; focus-visible rings add real keyboard-nav clarity.
4. **No new copy or numeric tells introduced.** Names stay real (Calhoun Foods, Riverbend Hardware), numbers stay organic (12, 8.3 days, 94.6%, 1,247.20, 0:56, 72%), no banned phrases.
